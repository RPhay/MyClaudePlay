# MyClaudePlay

A sandbox for learning and sharing Claude skills. This repository contains experiments, examples, and documentation exploring various capabilities of Claude and Claude Code.

Docs access: follow the `doc-search` rules emitted at session start — delegate `docs/` lookups to the `doc-search` agent, and wait for its actual result before acting on it. Never report that a doc-search operation ran, or what it found, before the result is in hand.
